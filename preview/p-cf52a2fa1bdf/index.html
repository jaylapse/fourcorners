v8 map reset itself?

The v8 client saves the map file when you log out, so a crash or a lost connection during the daily server restart can overwrite it. Keep a copy of the .otmm file somewhere safe and just paste it back if your map is gone. To stop it from ever being overwritten, right-click the .otmm file → Properties → tick Read-only (new areas you explore will then not be saved until you untick it).

Still not smooth? A few PC settings that often help the old client

  • Stuttering? Make a shortcut to Tibia.exe → right-click → Properties → in Target add engine 1 at the very end, after the closing quote: "C:\Games\Tibia772\Tibia.exe" engine 1
  • Turn off V-Sync for Tibia: NVIDIA Control Panel → Manage 3D settings → Program Settings → add Tibia.exe → Vertical sync: Off. (AMD: Adrenalin → Gaming → Tibia → Wait for Vertical Refresh: Off.)
  • Use your graphics card: Windows Settings → System → Display → Graphics → add Tibia.exe → Options → High performance.
  • Disable fullscreen optimizations: right-click Tibia.exe → Properties → Compatibility → tick "Disable fullscreen optimizations".
  • Streaming with OBS? Use Window Capture instead of Game Capture for the 7.72 client.

Need help or want to chat? Open the Game Chat channel in-game to talk with other players, ask questions and share what you know.

Tasks: You can find tasks at any post office NPC.

Looking for someone? Everything is in-game:

!character "namelevel, vocation, city and guild
!deathlist "namerecent deaths
!highscoretop 50 (add "magic, "sword …)
!guildlistall guilds
!guildinfo "namemembers of a guild

Type !commands in-game for the full list. The most useful ones:

  • !online – who is playing right now
  • !tasklist – every kill task, !task shows your current one
  • !highscore and !character "name – top lists and character info
  • !serverinfo and !uptime – server rates and uptime
  • !kills and !deathlist – your frags and recent deaths
  • !guild – found a guild, !buyhouse while facing a house door
  • !share – toggle experience sharing in a party
  • !cast – stream your gameplay to other players
