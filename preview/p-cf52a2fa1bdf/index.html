v8 map reset itself?

The v8 client saves the map file when you log out, so a crash or a lost connection during the daily server restart can overwrite it. Keep a copy of the .otmm file somewhere safe and just paste it back if your map is gone. To stop it from ever being overwritten, right-click the .otmm file → Properties → tick Read-only (new areas you explore will then not be saved until you untick it).

Fix lag

Still not smooth? A few PC settings that often help the old client

  1. Stuttering?

    Make a shortcut to Tibia.exe → right-click → Properties → in Target add engine 1 at the very end, after the closing quote: "C:\Games\Tibia772\Tibia.exe" engine 1

  2. Turn off V-Sync for Tibia

    NVIDIA Control Panel → Manage 3D settings → Program Settings → add Tibia.exe → Vertical sync: Off. (AMD: Adrenalin → Gaming → Tibia → Wait for Vertical Refresh: Off.)

  3. Use your graphics card

    Windows Settings → System → Display → Graphics → add Tibia.exe → Options → High performance.

  4. Disable fullscreen optimizations

    Right-click Tibia.exe → Properties → Compatibility → tick "Disable fullscreen optimizations".

  5. Streaming with OBS?

    Use Window Capture instead of Game Capture for the 7.72 client.
